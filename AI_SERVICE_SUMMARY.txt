                    ROADWATCH AI SERVICE — WHAT IT DOES
═══════════════════════════════════════════════════════════════════════════════

📋 INPUT TO AI:
─────────────────────────────────────────────────────────────────────────────
1. Evidence (Image/Video):
   - Photo: JPEG or PNG (uploaded by citizen)
   - Video: MP4 or MOV (uploaded by citizen)

2. Context:
   {
     "reported_category": "helmet" OR "triple-riding" OR "red-light",
     "vehicle_number": "DL01AB1234",
     "location": "Delhi, Connaught Place",
     "citizen_description": "Person riding motorcycle without helmet"
   }


🔍 WHAT AI ANALYZES:
─────────────────────────────────────────────────────────────────────────────
For HELMET violation:
  → Look for person on motorcycle WITHOUT safety helmet
  → Verify headgear compliance (Indian MVA Section 129-2019)
  → Check if turban/religious exemption might apply

For TRIPLE-RIDING violation:
  → Count actual riders on vehicle
  → Verify more than 2 people on two-wheeler (Indian MVA Section 128-1)
  → Distinguish sidecar, stationary bystanders from riders

For RED-LIGHT violation:
  → Check if vehicle crossed stop line during RED signal
  → Distinguish lawful left-turn yields from illegal crossing
  → Verify signal state (flashing vs continuous red)

📊 WHAT EACH FIELD MEANS:
─────────────────────────────────────────────────────────────────────────────

1. RELEVANCE (Is this evidence about the reported violation?)
   ├─ "relevant"   → Yes, clearly shows reported violation
   ├─ "irrelevant" → No, shows something completely different
   └─ "uncertain"  → Maybe, unclear or borderline

2. RELEVANCE_CONFIDENCE (How sure is AI the evidence is relevant?)
   ├─ 0-30   → Very uncertain
   ├─ 30-60  → Somewhat uncertain
   ├─ 60-80  → Fairly confident
   └─ 80-100 → Very confident

3. VIOLATION_CONFIDENCE (How sure is AI the violation happened?)
   ├─ 0-30   → No violation likely
   ├─ 30-60  → Unclear if violation
   ├─ 60-80  → Violation likely
   └─ 80-100 → Clear violation

4. RECOMMENDATION (What should officer do?)
   ├─ "recommend-approve"       → Approve this report
   ├─ "recommend-reject"        → Reject this report
   ├─ "needs-human-judgment"    → Officer must decide (AI uncertain)
   └─ "screen-out-irrelevant"   → Not about reported violation

5. OBSERVATIONS (Specific things AI saw)
   └─ Multiple entries with text + timestamps (for video)

6. ATTACHMENT_RELEVANCE (Per media file analysis)
   └─ Separate assessment for each image/video uploaded

7. RULE_NOTES (Indian law references)
   └─ Citations to Motor Vehicles Act sections

🔄 FLOW IN ROADWATCH MVP:
─────────────────────────────────────────────────────────────────────────────

Step 1: Citizen submits report (with image)
   ↓ (doesn't wait for AI)
Step 2: System enqueues AI job (async background process)
   ↓
Step 3: AI Worker picks up job (background)
   ├─ Reads image/video from disk
   ├─ Reads report context from database
   ├─ Calls OpenAI/Gemini API
   ├─ Gets assessment (structure above)
   ├─ Validates JSON against schema
   └─ Stores in database
   ↓
Step 4: Officer reviews report
   ├─ Sees AI recommendation
   ├─ Sees confidence scores
   ├─ Reads observations
   ├─ Makes FINAL decision (can override AI)
   └─ Awards points
   ↓
Step 5: Citizen sees decision


❌ IF NO API KEYS PROVIDED:

When OPENAI_API_KEY and GEMINI_API_KEY both missing:

  → Officer sees: "AI processing unavailable"
  → Officer CAN STILL approve/reject manually
  → NO API CALLS MADE
  → Fully functional without AI integration


🎓 INDIAN LAW REFERENCES (AI cites):
─────────────────────────────────────────────────────────────────────────────

MVA-129-2019: Helmet requirement
  → Motorcycle rider must wear helmet
  → Turban exemption possible (jurisdiction-dependent)

MVA-128-1: Triple-riding rule  
  → Max 2 persons on two-wheeler motorcycle
  → Cannot carry more than one passenger

MVA-119-1: Traffic signal compliance
  → Must stop at red signal
  → Cannot cross during red phase

MVDR-12-1: Driving regulations (2017)
  → Lane control and signal compliance rules


🚨 AI LIMITATIONS (Officer Must Know):
─────────────────────────────────────────────────────────────────────────────

AI CANNOT:
  ❌ Verify turban vs religious exemption status
  ❌ Check vehicle registration or ownership
  ❌ Determine rider's age or legal status
  ❌ Verify helmet safety standards/fastening
  ❌ Read all license plate digits (OCR limits)
  ❌ Identify vehicle owner vs hired rider
  ❌ Check if rider has valid license
  ❌ Assess if left-turn maneuver was lawful

AI CAN:
  ✓ Detect absence of visible head protection
  ✓ Count riders on vehicle
  ✓ Verify traffic signal color/status
  ✓ Identify violation category from images
  ✓ Flag uncertainty for officer decision
  ✓ Cite applicable Indian law sections
