## 🎯 Implementation Details

### Table Definitions

#### 1. `reports` Table
Core report metadata and status tracking.

```sql
CREATE TABLE reports (
    id TEXT PRIMARY KEY,
    -- Identifiers
    citizen_id TEXT NOT NULL,
    
    -- Report metadata
    violation_type TEXT NOT NULL,  -- helmet, triple-riding, red-light, speeding
    location TEXT,                  -- "Intersection of MG Road and Brigade Road, Bangalore"
    
    -- Status & points
    status TEXT NOT NULL DEFAULT 'submitted',
        -- submitted → evidence-screening → awaiting-review → approved/rejected/info-requested → resubmitted
    provisional_points INTEGER DEFAULT 0,  -- 0, 2, 3 based on violation_type
    
    -- Metadata
    created_at TEXT NOT NULL,       -- ISO-8601 UTC timestamp
    updated_at TEXT NOT NULL,       -- Last status change
    
    -- Operational
    screening_notes TEXT,           -- Technical screening summary (blur, resolution, etc.)
    officer_notes TEXT              -- Officer review notes or rejection reason
);

-- Indexes for query performance
CREATE INDEX idx_reports_citizen_id ON reports(citizen_id);
CREATE INDEX idx_reports_status ON reports(status);
CREATE INDEX idx_reports_created_at ON reports(created_at DESC);
```

**Key Constraints:**
- `id`: UUID generated by application (e.g., `uuid.uuid4().hex[:16]`)
- `status`: Enum-like values; state transitions managed by M4.2 API
- `provisional_points`: Set at approval time based on `violation_type`
- `created_at`, `updated_at`: Always UTC ISO-8601 strings (e.g., `2026-11-01T18:48:25Z`)

#### 2. `events` Table
Append-only audit trail of all status changes and actions.

```sql
CREATE TABLE events (
    id TEXT PRIMARY KEY,
    -- Report reference
    report_id TEXT NOT NULL,
    
    -- Event data
    event_type TEXT NOT NULL,  -- submitted, screened, screening-failed, queued, approved, rejected, clarification-requested, resubmitted
    actor TEXT NOT NULL,       -- citizen-<id>, officer-<id>, system
    reason TEXT,               -- Optional: rejection reason, screening failure note
    
    -- Metadata
    created_at TEXT NOT NULL,  -- ISO-8601 UTC timestamp
    
    -- Data snapshot (immutable record of what changed)
    old_status TEXT,           -- Previous status (NULL if first event)
    new_status TEXT NOT NULL,  -- Current status after event
    provisional_points INTEGER,  -- Points awarded (if approved)
    
    FOREIGN KEY (report_id) REFERENCES reports(id) ON DELETE CASCADE
);

-- Indexes
CREATE INDEX idx_events_report_id ON events(report_id);
CREATE INDEX idx_events_created_at ON events(created_at DESC);
```

**Key Constraints:**
- `id`: UUID generated by application
- `event_type`: Fixed set of event names
- `actor`: Format: `citizen-<uuid>` or `officer-<uuid>` or `system`
- `created_at`: UTC ISO-8601, never updated (immutable)
- All events MUST be INSERT-only; never UPDATE/DELETE (append-only compliance)

---

#### 3. `media` Table
Media file metadata and technical screening results.

```sql
CREATE TABLE media (
    id TEXT PRIMARY KEY,
    -- File reference
    report_id TEXT NOT NULL,
    
    -- File metadata
    filename TEXT NOT NULL,      -- Original upload name (e.g., "helmet_violation_20261101.jpg")
    file_size_bytes INTEGER NOT NULL,
    mime_type TEXT NOT NULL,     -- image/jpeg, video/mp4, etc.
    
    -- Integrity & deduplication
    sha256_hash TEXT NOT NULL UNIQUE,  -- SHA-256 hex digest for duplicate detection
    
    -- Storage (local path for MVP; cloud URL in Phase 2)
    storage_path TEXT NOT NULL,  -- e.g., "./media_store/report_abc123/media_xyz789.jpg"
    
    -- Technical screening results
    screening_status TEXT DEFAULT 'pending',  -- pending, passed, failed
    screen_blur_score REAL,      -- 0.0–1.0 (1.0 = maximum blur)
    screen_blur_flagged BOOLEAN DEFAULT FALSE,  -- True if blur > threshold
    screen_resolution_width INTEGER,
    screen_resolution_height INTEGER,
    screen_resolution_flagged BOOLEAN DEFAULT FALSE,  -- True if < 1280x720 for video, < 640x480 for image
    screen_frame_count INTEGER,  -- For videos: total frames
    screen_frame_sampled_count INTEGER,  -- For videos: frames analyzed
    
    -- AI Screening (optional, Phase 2)
    ai_screening_status TEXT,    -- pending, completed, failed, not-requested
    ai_screening_result TEXT,    -- JSON: {plausible: bool, confidence: 0–100, notes: str}
    ai_screened_at TEXT,
    
    -- Metadata
    uploaded_at TEXT NOT NULL,   -- ISO-8601 UTC
    
    FOREIGN KEY (report_id) REFERENCES reports(id) ON DELETE CASCADE
);

-- Indexes
CREATE INDEX idx_media_report_id ON media(report_id);
CREATE INDEX idx_media_sha256_hash ON media(sha256_hash);
CREATE INDEX idx_media_uploaded_at ON media(uploaded_at DESC);
```

**Key Constraints:**
- `id`: UUID generated by application
- `sha256_hash`: Unique (enforces deduplication; duplicate upload rejected at M3.2)
- `storage_path`: Always under `./media_store/` (local MVP); relative paths for portability
- Screening columns default to NULL (populated only after screening runs)
- `ai_screening_result`: Stored as JSON string for flexibility; parsed by app layer

---

#### 4. `operators` Table
Operational state for `runtime_controls.py` state machine.

```sql
CREATE TABLE operators (
    id TEXT PRIMARY KEY,
    -- Operator reference
    report_id TEXT NOT NULL,
    
    -- Control state
    control_type TEXT NOT NULL,  -- approval, rejection, requeue, etc.
    control_state TEXT NOT NULL, -- requested, in-progress, completed, failed
    
    -- Control metadata
    requested_by TEXT NOT NULL,  -- actor ID
    requested_at TEXT NOT NULL,  -- ISO-8601 UTC
    completed_at TEXT,           -- NULL until completion
    
    -- Result (populated on completion)
    result_json TEXT,            -- JSON: {status: 'ok'|'error', message: str, ...}
    
    FOREIGN KEY (report_id) REFERENCES reports(id) ON DELETE CASCADE
);

-- Index
CREATE INDEX idx_operators_report_id ON operators(report_id);
```

**Key Constraints:**
- Used by `runtime_controls.py` to track long-running operations
- `result_json`: Stores operation outcome for audit trail

### Database Connection & Initialization

#### In `bootstrap.py`

```python
import sqlite3
from contextlib import contextmanager
from pathlib import Path

class DatabaseConnection:
    """SQLite connection for MVP (single connection; PostgreSQL connection pool in Phase 2)."""
    
    def __init__(self, db_path: str = "./roadwatch.db"):
        self.db_path = Path(db_path)
        self.connection = None
    
    def connect(self):
        """Initialize SQLite connection with WAL mode (better concurrency)."""
        self.connection = sqlite3.connect(str(self.db_path), check_same_thread=False)
        self.connection.row_factory = sqlite3.Row  # Access columns by name
        
        # Enable WAL mode for better concurrent access
        self.connection.execute("PRAGMA journal_mode=WAL")
        self.connection.execute("PRAGMA foreign_keys=ON")
        
        # Create schema if not exists
        self._init_schema()
    
    def _init_schema(self):
        """Create all tables if they don't exist."""
        with self.connection as conn:
            conn.executescript("""
                CREATE TABLE IF NOT EXISTS reports (
                    id TEXT PRIMARY KEY,
                    citizen_id TEXT NOT NULL,
                    violation_type TEXT NOT NULL,
                    location TEXT,
                    status TEXT NOT NULL DEFAULT 'submitted',
                    provisional_points INTEGER DEFAULT 0,
                    created_at TEXT NOT NULL,
                    updated_at TEXT NOT NULL,
                    screening_notes TEXT,
                    officer_notes TEXT
                );
                
                CREATE INDEX IF NOT EXISTS idx_reports_citizen_id ON reports(citizen_id);
                CREATE INDEX IF NOT EXISTS idx_reports_status ON reports(status);
                CREATE INDEX IF NOT EXISTS idx_reports_created_at ON reports(created_at DESC);
                
                CREATE TABLE IF NOT EXISTS events (
                    id TEXT PRIMARY KEY,
                    report_id TEXT NOT NULL,
                    event_type TEXT NOT NULL,
                    actor TEXT NOT NULL,
                    reason TEXT,
                    created_at TEXT NOT NULL,
                    old_status TEXT,
                    new_status TEXT NOT NULL,
                    provisional_points INTEGER,
                    FOREIGN KEY (report_id) REFERENCES reports(id) ON DELETE CASCADE
                );
                
                CREATE INDEX IF NOT EXISTS idx_events_report_id ON events(report_id);
                CREATE INDEX IF NOT EXISTS idx_events_created_at ON events(created_at DESC);
                
                CREATE TABLE IF NOT EXISTS media (
                    id TEXT PRIMARY KEY,
                    report_id TEXT NOT NULL,
                    filename TEXT NOT NULL,
                    file_size_bytes INTEGER NOT NULL,
                    mime_type TEXT NOT NULL,
                    sha256_hash TEXT NOT NULL UNIQUE,
                    storage_path TEXT NOT NULL,
                    screening_status TEXT DEFAULT 'pending',
                    screen_blur_score REAL,
                    screen_blur_flagged BOOLEAN DEFAULT FALSE,
                    screen_resolution_width INTEGER,
                    screen_resolution_height INTEGER,
                    screen_resolution_flagged BOOLEAN DEFAULT FALSE,
                    screen_frame_count INTEGER,
                    screen_frame_sampled_count INTEGER,
                    ai_screening_status TEXT,
                    ai_screening_result TEXT,
                    ai_screened_at TEXT,
                    uploaded_at TEXT NOT NULL,
                    FOREIGN KEY (report_id) REFERENCES reports(id) ON DELETE CASCADE
                );
                
                CREATE INDEX IF NOT EXISTS idx_media_report_id ON media(report_id);
                CREATE INDEX IF NOT EXISTS idx_media_sha256_hash ON media(sha256_hash);
                CREATE INDEX IF NOT EXISTS idx_media_uploaded_at ON media(uploaded_at DESC);
                
                CREATE TABLE IF NOT EXISTS operators (
                    id TEXT PRIMARY KEY,
                    report_id TEXT NOT NULL,
                    control_type TEXT NOT NULL,
                    control_state TEXT NOT NULL,
                    requested_by TEXT NOT NULL,
                    requested_at TEXT NOT NULL,
                    completed_at TEXT,
                    result_json TEXT,
                    FOREIGN KEY (report_id) REFERENCES reports(id) ON DELETE CASCADE
                );
                
                CREATE INDEX IF NOT EXISTS idx_operators_report_id ON operators(report_id);
            """)
    
    def close(self):
        """Close database connection."""
        if self.connection:
            self.connection.close()
    
    @contextmanager
    def transaction(self):
        """Context manager for database transactions."""
        try:
            yield self.connection
            self.connection.commit()
        except Exception as e:
            self.connection.rollback()
            raise e

# Global instance (initialized at app startup in M2)
db_connection: DatabaseConnection = None

def init_database(db_path: str = "./roadwatch.db") -> DatabaseConnection:
    """Initialize database and return connection."""
    global db_connection
    db_connection = DatabaseConnection(db_path)
    db_connection.connect()
    return db_connection

def get_db() -> DatabaseConnection:
    """Get current database connection."""
    if db_connection is None:
        raise RuntimeError("Database not initialized. Call init_database() at app startup.")
    return db_connection
```
